# Android app

The TV Tracker Android app connects to the same server as the website (`tvtracker.melamoud.com`) and uses your Trakt login. It keeps the same data as the web client, with a compact mobile layout.

Action buttons on a card (and on the title page, and a season’s **Mark season watched** row) stay on one line. Swipe that row left or right when they don’t fit — there is no scrollbar. An arrow at the left or right edge means more buttons are off that side. The arrow is only a hint; swipe the row itself.

## What it does

- **My Shows / My Movies** — the same list filters as the web (status, **Lists…**, **Upcoming / Theater / Streaming**, title search), each as a compact dropdown with checkmarks. Choices are remembered on the server (same as the website). **List** vs **Newest aired** is the same server sort as the website (pins on top; movies by release date; shows by latest episode air date). Switching that menu reloads from the server. Cards show genres, **Found on** (tap a service to open it), **Progress**, **Watch**, and **Feedback** (rating plus an optional Trakt review for the movie or show). Pin, set lists, **Found on…** (with **Search** per service), rate, favorite, IMDb, Trailer, and Trakt are in the ⋮ menu. A pinned show stays in the pinned group at the top, same as the website. **More** includes **Search actor**, which opens Search for that person. Tap the card to open the **title page**.
- **Latest movies / Latest shows** — the same Trakt DB update feed as the web, with **Matches only**, **All titles**, year range, multi-select genres, **Hide watched**, **Hide list titles**, and a **Load older** Trakt page control. The review marker shows where you are up to; titles at or older than the marker are hidden by default, and the top-bar menu has a **Show reviewed** toggle. The same menu has **Jump to marker** and **Clear marker**. Cards show a gold **Preference match** line when the title matches your genres or keywords. Cards use **Set lists…** as the main action and **Feedback** (rating plus an optional review) on the card; **Rate**, **Favorite**, **Found on…**, **Hide recommendation**, and external links are in the ⋮ menu. **More** includes **Search actor**. The overflow item badge is **matches / unreviewed** (same remaining pile as the website).
- **Recommended movies / Recommended shows** — personalized Trakt recommendations, filtered by your Preferences genres, with the same year/genre/availability filters as the web. Inline actions are **Set lists**, **Found on**, and **Feedback**; **Rate**, **Favorite**, **Hide recommendation**, and external links are in the ⋮ menu. **More** includes **Search actor**. A **Refresh Trakt** button fetches a fresh recommendation set from Trakt. The overflow item badge is **matches / remaining** once recs are cached.
- **Search** — find titles on Trakt and add them to your lists. Type at least **2 characters**, then tap the **Search** icon (or press search on the keyboard). The empty state tells you to search when the box is short, and “no matches” only after a real query. **Type** and **Filters** are compact menus (defaults hide already-watched and already-listed titles; those choices are remembered). Filters also include **Year** and multi-select **Genres**. A second search field lets you search for an **actor**; selecting an actor filters results to titles with that person. Cards show **Found on** and **Feedback**. Tap a result for the title page. The ⋮ menu includes **Pin**, **Found on…** with a **Search** action per service, plus IMDb, Trailer, and Trakt.
- **Alerts** — the same in-app alerts as the website, including **Found on** chips (tap to open the service), streaming lines, purple **Preference match** genre/keyword tags, and poster badges: **Episode** / **Season** / **Streaming** / **Movie** / **List** / **Actor** / **Admin**. Episode cards look like **The Ark S3E9 Critical Failure** plus a **New episode** tag; streaming and list alerts put the service or list names in that tag. New alerts get a thick gold frame, a gold title bar, and an **Ack** action (seen — stays in the list). After Ack, **Unack** puts that alert back in Inbox. The nav badge is **new/active** (e.g. `3/12`). **Inbox** filters to those gold rows only, ungrouped. **Pin** a show or movie so all of its alerts stay at the top; the pin control is in the ⋮ menu, along with **Lists** and **Found on…** (edits where you found the title). Grouped show rows also have **Found on** in ⋮. **Progress** is the first inline action on every show-linked alert, followed by **Mark watched** when the alert is a title (a movie, or a show added to a list, matched to a favorite actor, or newly streaming — not an episode or season), then **Rate**, **Ack** / **Unack**, and **Dismiss** (clears the alert — not the same as marking the title watched; **Restore** brings it back). **Newest first** / **Oldest first** and **Grouped by show** match the website. Hide-dismissed is remembered. Tap the card to open the title page.
- **Title page** — movie/show detail matching the website: overview, genres, preference/list/watched tags, streaming and Found on (with **Found on…** to edit; each row has **Search**), **Pin** / lists / rate / favorite / **Feedback** (rating and review together) / watched, IMDb / Trailer / Homepage / Trakt, and cast (favorite actor + search that actor’s titles). Shows have **Series progress**.
- **Progress** — mark episodes, a whole season, or the whole series watched / unwatched. Writes to Trakt. A **Refresh from Trakt** option reloads the latest watched state. Each episode has **Rate / Review**, which loads your existing Trakt rating and review and can mark that episode watched in the same save.
- **Preferences** — all the web preferences that affect the app: streaming services (default + custom, with optional **Suggest as default** to admin), genres/keywords/excluded genres, Trakt list visibility (**Show in menu** / **Auto-select** / **Alerts**), **Create on Trakt** / **Delete** for personal lists, **Google Calendar** (connect an account, pick a calendar used only for these meetings; meetings for Wishlist and Auto-select titles; reminder is popup, email, or none, default popup 1 day before), favorite-actor management (**Titles** opens Search for that actor), alert type toggles, review marker actions (**Clear** / **Caught up**), and the daily preferences reminder (**Snooze** / **Enable**). The first-login wizard is the same as the web.
- **Admin** (admin users only) — dashboard stats, release-check trigger, user management, streaming-service defaults, pending service suggestions, and scheduler editing (intervals, enabled toggles, timezone). Matches the web admin screen.
- **Home-screen widget** — long-press the home screen → Widgets → **TV Tracker**. Resize it for more rows and width. The header shows the app icon and **TV Tracker ·** mode; the swap button cycles **Shows Progress** / **Movies** / **Alerts** / **Inbox**. Movies are released titles you have not watched. Inbox is ungrouped new alerts only. On the Alerts view, new rows are gold-highlighted (the show group stays put; expand to see which episode is new). The list scrolls. Tap a title or poster to open that show, movie, or alert in the app. The checkmark asks before marking the next episode (Shows) or the movie (Movies) watched. That confirm dialog shows **Cancel** and **Mark watched** — the server updates Trakt and advances the same progress summary the website uses, so the row leaves or moves to the next episode after refresh (even when the full progress cache was cleared by a background sync). If mark fails, a short toast explains it. Refresh on the widget reloads from the server (same cache as the app).

## Filter bars

The filter toolbar on each list is compact: the most-used choices stay on the main row, and the rest are under a **More** button. The badge on **More** shows how many extra filters are active. Tapping it opens a bottom sheet with year range, genre chips, per-page size, and the **Refresh Trakt** action. Each screen puts the choices you use most often in the main row.

## Pagination

When a list has multiple pages, the bottom bar shows **Previous**, the current page number, and **Next**. Tap the page number to open a **Go to page** dialog and jump directly to any page.

## Version

The current app version is shown in the top bar and just above the bottom navigation bar (**1.0.5** and later). It bumps with each release so you can confirm you have the latest APK.

## Refresh

Pull down on any list, or tap the refresh icon. That reloads from the TV Tracker server (the same cache the website uses). A **Refresh Trakt** option on My pages, Recommended, and Progress forces a fresh Trakt pull for that data. Lists also reload when you return to them (including after Progress).

## Login

There is no local password. Tap **Login with TraktTV**, authorize in the browser, then the app opens again to finish. If the browser stays open, tap **Open TV Tracker**.

Stay signed in until you tap **Log out**.
