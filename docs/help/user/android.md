# Android app

The TV Tracker Android app connects to the same server as the website (`tvtracker.melamoud.com`) and uses your Trakt login.

## What it does

- **My Shows / My Movies** — the same list filters as the web (status, Lists…, Upcoming / Theater / Streaming, title search), each as a compact dropdown with checkmarks. Cards show **Progress** and **Watch**; pin, set lists, rate, and favorite are in the ⋮ menu.
- **Search** — find titles on Trakt and add them to your lists. **Type** and **Filters** are compact menus (defaults hide already-watched and already-listed titles).
- **Alerts** — the same in-app alerts as the website. Episode/season cards have **Progress**.
- **Progress** — mark episodes or a whole season watched / unwatched. Writes to Trakt.

Latest movies/shows and Recommended screens are website-only for now.

## Login

There is no local password. Tap **Login with TraktTV**, authorize in the browser, then the app opens again to finish. If the browser stays open, tap **Open TV Tracker**.

Stay signed in until you tap **Log out**.
