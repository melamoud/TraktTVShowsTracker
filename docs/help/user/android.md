# Android app

The TV Tracker Android app connects to the same server as the website (`tvtracker.melamoud.com`) and uses your Trakt login. It keeps the same data as the web client, with a compact mobile layout.

## What it does

- **My Shows / My Movies** — the same list filters as the web (status, **Lists…**, **Upcoming / Theater / Streaming**, title search), each as a compact dropdown with checkmarks. Choices are remembered on the server (same as the website). **List** vs **Newest aired** is the same server sort as the website (pins on top; movies by release date; shows by latest episode air date). Switching that menu reloads from the server. Cards show **Found on** (tap a service to open it), **Progress**, and **Watch**; pin, set lists, **Found on…** (with **Search** per service), rate, and favorite are in the ⋮ menu. Tap the card to open the **title page**.
- **Latest movies / Latest shows** — the same Trakt DB update feed as the web, with **Matches only**, **All titles**, year range, multi-select genres, **Hide watched**, **Hide list titles**, and a **Load older** Trakt page control. The review marker shows where you are up to; tap the top-bar menu to **Jump to marker** or **Clear marker**. Cards use **Set lists…** as the main action; **Rate**, **Favorite**, **Found on…**, **Hide recommendation**, and external links are in the ⋮ menu.
- **Recommended movies / Recommended shows** — personalized Trakt recommendations, filtered by your Preferences genres, with the same year/genre/availability filters as the web. Inline actions are **Set lists** and **Found on**; **Rate**, **Favorite**, **Hide recommendation**, and external links are in the ⋮ menu. A **Refresh Trakt** button fetches a fresh recommendation set from Trakt.
- **Search** — find titles on Trakt and add them to your lists. **Type** and **Filters** are compact menus (defaults hide already-watched and already-listed titles; those choices are remembered). Filters also include **Year** and multi-select **Genres**. A second search field lets you search for an **actor**; selecting an actor filters results to titles with that person. Cards show **Found on**. Tap a result for the title page. The ⋮ menu includes **Found on…** with a **Search** action per service.
- **Alerts** — the same in-app alerts as the website, including **Found on** (tap to open the service), streaming lines, purple **Preference match** genre/keyword tags, and poster badges: **Episode** / **Season** / **Streaming** / **Movie** / **List** / **Actor** / **Admin**. Episode titles look like **The Agency S3E5**. **Pin** a show or movie so all of its alerts stay at the top. **Progress** is on every show-linked alert. Inline actions on each alert are **Watch**, **Lists**, **Found on**, and **Rate**. **Newest first** / **Oldest first** and **Grouped by show** match the website. Hide-read is remembered. Tap the card to open the title page.
- **Title page** — movie/show detail matching the website: overview, genres, preference/list/watched tags, streaming and Found on (with **Found on…** to edit; each row has **Search**), lists / rate / favorite / review / watched, IMDb / Trailer / Homepage / Trakt, and cast (favorite actor + search that actor’s titles). Shows have **Series progress**.
- **Progress** — mark episodes or a whole season watched / unwatched. Writes to Trakt. A **Refresh from Trakt** option reloads the latest watched state. Each episode has a **Rate** button for rating and commenting.
- **Preferences** — all the web preferences that affect the app: streaming services (default + custom, with optional **Suggest as default** to admin), genres/keywords/excluded genres, Trakt list visibility (**Show in menu** / **Auto-select** / **Alerts**), favorite-actor management, alert type toggles, review marker actions (**Clear** / **Caught up**), and the daily preferences reminder (**Snooze** / **Enable**). The first-login wizard is the same as the web.
- **Admin** (admin users only) — dashboard stats, release-check trigger, user management, streaming-service defaults, pending service suggestions, and scheduler editing (intervals, enabled toggles, timezone). Matches the web admin screen.
- **Home-screen widget** — long-press the home screen → Widgets → **TV Tracker**. Resize it for more rows and width. The header shows the app icon and **TV Tracker ·** mode; the swap button cycles **Shows Progress** / **Movies** / **Alerts**. The list scrolls. Tap a title or poster to open that show, movie, or alert in the app. The checkmark asks before marking the next episode (Shows) or the movie (Movies) watched. Refresh on the widget reloads from the server (same cache as the app).

## Refresh

Pull down on any list, or tap the refresh icon. That reloads from the TV Tracker server (the same cache the website uses). A **Refresh Trakt** option on My pages, Recommended, and Progress forces a fresh Trakt pull for that data. Lists also reload when you return to them (including after Progress).

## Login

There is no local password. Tap **Login with TraktTV**, authorize in the browser, then the app opens again to finish. If the browser stays open, tap **Open TV Tracker**.

Stay signed in until you tap **Log out**.
