# Review markers

Each catalog page (movies / shows) has **one** marker:

> “I reviewed everything older than this title.”

The marker uses the title’s **Trakt listing/update time**, not the theatrical release date. Rows at or older than the marker are **dimmed** so you can focus on newer items (you can still page into dimmed history).

You can **Clear marker** from Latest, or from Preferences after changing match filters.

## Edited titles stay reviewed

Latest is Trakt’s “recently changed” feed, so any metadata edit (poster, cast, release date) gives a title a new time and lifts it above your marker. When you set the marker (or **Caught up as of now**), the app also remembers every title at or below it. Those titles stay hidden (or dimmed with **Show reviewed**) after a later Trakt edit. **Clear marker** forgets them, so everything can show again.

## When you change genres / keywords

Purple matches shift. Markers stay on the same titles, which can hide newly matching rows below the marker. After saving Preferences you’ll be asked:

| Choice | Effect |
|--------|--------|
| **Keep markers** | Leave as-is |
| **Clear** (movie / show / both) | Remove dimming; re-review from the top |
| **Caught up as of now** | Set the marker on the **newest** feed title — everything currently listed is dimmed; only future Trakt updates stay undimmed |

Latest sync does **not** walk older Trakt pages down to your marker. Older pages load only when you page back. The marker dims titles already in the local cache.

The pagination underlines the page that contains your review marker so you can jump straight to the oldest page that still has unreviewed titles.
