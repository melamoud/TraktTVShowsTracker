# Review markers

Each catalog page (movies / shows) has **one** marker:

> “I reviewed everything older than this title.”

The marker uses the title’s **Trakt listing/update time**, not the theatrical release date. Rows at or older than the marker are **dimmed** so you can focus on newer items (you can still page into dimmed history).

Latest sync also uses your marker as the personal depth target: after the first ~30-day bootstrap, visits ensure the feed includes titles down through your marker, then load older Trakt pages only when you page further.
