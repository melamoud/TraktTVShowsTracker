# Login with TraktTV

1. Open the site and click **Login with TraktTV**
2. Sign in on Trakt (email or Google is fine on Trakt’s side)
3. Approve access for this application
4. You return here signed in

## Need a Trakt account?

Create one at [trakt.tv](https://trakt.tv). This app cannot create Trakt accounts for you.

## Operator note

The site owner must register a Trakt API application and configure `.env` — see `docs/SETUP.md`.
