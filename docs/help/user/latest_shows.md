# Latest shows

Same idea as [Latest movies](latest_movies): Trakt `/shows/updates` — recently added/changed **in Trakt’s database**, not airdate calendars. Same lazy sync and defaults (**recent years** + **Matches only** + **Hide list titles**).

Defaults to **Matches only** (purple genres/keywords). Use **Show all** for the full noisy feed. Titles already saved to your personal Trakt lists are hidden by default; use **Show list titles** to see them. Genres you **hide** in Preferences stay off this page even on Show all. Cards have a **Hide recommendation** button (Trakt “Not interested”) that removes the title from future Trakt recommendations even if it is not on the Recs page.

**Filter this page…** and Trakt-wide **Search** work the same as on [Latest movies](latest_movies). **Found on** chips and **Found on…** are on these cards too.
