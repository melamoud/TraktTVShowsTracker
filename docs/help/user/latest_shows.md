# Latest shows

Same idea as [Latest movies](latest_movies): Trakt `/shows/updates` — recently added/changed **in Trakt’s database**, not airdate calendars. Same lazy sync (full ~30-day first load, then down to your review marker, older pages on demand).

Hide watched is on by default. Review marker uses Trakt DB activity time.

**Streaming:** is read-only (TMDB). Use **My shows** for your local **Found on…** choices.
