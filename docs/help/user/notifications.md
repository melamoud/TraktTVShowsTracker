# Notifications

Same as [Alerts](release_alerts) — open **Alerts** in the nav.

Active rows are brighter; dimmed rows were dismissed. **Hide dismissed** (default) keeps the list to active only — use **Show dismissed** when you want history. **Newest first** / **Oldest first** sorts by time; **Pin** a show or movie to keep its alerts on top; **Grouped by show** collapses a show’s episode alerts until you expand them. Use **Dismiss** / **Restore** on each alert, or **Dismiss all** when any are active. Alerts also auto-dismiss when you **Watch** the episode/movie in this app (that updates the shared progress/watched cache immediately), or on the next alert refresh once the local cache already shows it watched.
