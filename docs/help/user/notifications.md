# Notifications

Same as [Alerts](release_alerts) — open **Alerts** in the nav.

Unread rows are brighter; dimmed rows are already read. **Hide read** (default) keeps the list to unread only — use **Show read** when you want history. **Newest first** / **Oldest first** sorts by time; **Pin** a show or movie to keep its alerts on top; **Grouped by show** collapses a show’s episode alerts until you expand them. Use **Mark read** / **Mark unread** on each alert, or **Mark all read** when any are unread. Alerts also auto-mark read when you **Watch** the episode/movie in this app (that updates the shared progress/watched cache immediately), or on the next alert refresh once the local cache already shows it watched.
