# Notifications

Same as [Alerts](release_alerts) — open **Alerts** in the nav.

Unread rows are brighter; dimmed rows are already read. **Hide read** (default) keeps the list to unread only — use **Show read** when you want history. Use **Mark read** / **Mark unread** on each alert, or **Mark all read** when any are unread. Alerts also auto-mark read when you **Watch** the episode/movie in this app, or on the next alert refresh once Trakt already has it watched.
