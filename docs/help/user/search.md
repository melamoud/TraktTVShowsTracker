# Search

## Trakt-wide Search

Use **Search** in the top navigation to find movies and shows in Trakt’s database (not only titles you already track).

1. Type at least **2 characters**
2. Choose **Movies**, **Shows**, or **Movies & shows**
3. Results use the same card layout as Latest: overview, genres, streaming lines, preference tags, watchlist/watched status
4. **Add to lists…** / **Mark watched** / **Rate…** / **Favorite** work the same as elsewhere; shows also link to **Progress**

Exact title matches are listed before broader fuzzy hits.

## Search within a page

My movies / My shows, Latest, and Recommended each have a **Search titles in this list…** box in the toolbar.

- Filters the **current page’s filters** (lists, watched, matches, etc.) by title or year
- Searches the **full filtered set**, then paginates — not only the current page
- Query is **not** remembered when you leave the page (clear with **Clear**, or drop `q` from the URL)

To find something you do not already have on a list, use the nav **Search** page instead.
